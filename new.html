How to evaluate a new LitBuy find

  1. Start from a current source. Use LitBuyDocs recent posts, this spreadsheet, category pages, or a live marketplace link as the first route.
  2. Confirm live product facts. Check price, stock, size chart, color, domestic shipping, seller notes, and return rules before submitting the order.
  3. Save a clean route. Keep only links with clear product information, usable category placement, and enough seller detail to compare later.
  4. Plan before ordering. Weight, volume, packaging, restricted items, and destination country can change whether a new find is worth adding to a haul.
